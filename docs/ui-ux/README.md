# UI/UX HealthPlatform

Ce dossier constitue la source de vérité visuelle de HealthPlatform. Il transforme les exigences du cahier UI/UX en règles vérifiables et en contrats de composants.

Documents :

- [Charte graphique](GraphicCharter.md)
- [Design System](DesignSystem.md)
- [Bibliothèque de composants](ComponentLibrary.md)
- [Wireframes](Wireframes.md)
- [Maquettes fonctionnelles](ScreenMockups.md)
- [Validation UI/UX](Validation.md)

Principes directeurs : confiance, maîtrise patient, clarté clinique, accessibilité WCAG 2.1 AA et transparence sur l’origine des données. Une donnée absente est affichée comme absente; aucun indicateur clinique n’est simulé.
